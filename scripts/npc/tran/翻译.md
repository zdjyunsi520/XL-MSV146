# NPC文件翻译流程

## 概述
手动翻译MapleStory NPC JavaScript文件中的对话文本，保留游戏特殊符号（#b, #k, #l, #m等）。

## 目录结构
```
scripts/npc/
├── *.js          # 原始NPC文件
├── tran/         # 翻译后的文件存放目录
├── translate_zh.txt  # 翻译对照库
├── replace.py    # 批量替换脚本
└── 翻译.md       # 本文档
```

## 翻译流程

### 第一步：找出未翻译的文件
```powershell
cd e:\github\MapleStoryV146\Service\SpiritMS\scripts\npc
$translated = @()
Get-Content translate_zh.txt | ForEach-Object {
    $parts = $_ -split '\|'
    if ($parts.Length -ge 1) { $translated += $parts[0] -replace 'npc/', '' }
}
Get-ChildItem tran -Name *.js | Where-Object { $_ -notin $translated } | Select-Object -First 30
```

### 第二步：读取原始文件，提取需要翻译的对话
使用Read工具读取原始文件（不是tran目录里的），找出以下类型的对话：
- `cm.sendOk("...")`
- `cm.sendSimple("...")`
- `cm.sendYesNo("...")`
- `cm.sendNext("...")`
- `cm.sendNextPrev("...")`
- `cm.askAcceptDecline("...")`
- `cm.sendGetNumber("...")`
- `cm.sendAndroidStyle("...")`

### 第三步：将翻译添加到translate_zh.txt
格式：`npc/文件名.js|英文原文|中文翻译`

示例：
```
npc/10200.js|If you wish to experience what it's like to be a Bowmen, come see me again.|如果你想体验弓箭手的感觉，再来找我。
```

### 保留的特殊符号
- `#b` - 蓝色文字
- `#k` - 黑色文字
- `#l` - 选项链接
- `#m` - 地图ID
- `#r` - 红色文字
- `#e` - 强调
- `#d` - 灰色文字
- `#h0#` - 玩家名称占位符
- `#t物品ID#` - 物品名称占位符
- `#pNPCID#` - NPC名称占位符
- `#i物品ID#` - 物品图标占位符
- `\r\n` - 换行符

### 第四步：运行替换脚本
```powershell
cd e:\github\MapleStoryV146\Service\SpiritMS\scripts\npc
python replace.py
```

### 第五步：验证翻译结果
使用Read工具读取tran目录下的翻译后文件，确认中文已正确替换。

### 第六步：检查进度

## replace.py脚本内容
```python
import os
import shutil

# 读取翻译文件
translations = {}
with open('translate_zh.txt', 'r', encoding='utf-8') as f:
    for line in f:
        line = line.strip()
        if not line:
            continue
        parts = line.split('|')
        if len(parts) == 3:
            filepath, en_text, zh_text = parts
            filename = os.path.basename(filepath)
            if filename not in translations:
                translations[filename] = []
            translations[filename].append((en_text, zh_text))

# 执行替换
tran_dir = 'tran'
for filename, pairs in translations.items():
    src_path = os.path.join(tran_dir, filename)
    if not os.path.exists(src_path):
        print(f"文件不存在: {src_path}")
        continue

    # 读取源文件
    with open(src_path, 'rb') as f:
        raw = f.read()
    try:
        content = raw.decode('utf-8')
    except:
        content = raw.decode('latin-1')

    # 执行替换
    for en_text, zh_text in pairs:
        content = content.replace(en_text, zh_text)

    # 保存替换后的文件
    with open(src_path, 'w', encoding='utf-8') as f:
        f.write(content)

    print(f"已替换完成: {src_path}")

print("批量替换完成！")
```

## 注意事项
1. 每次翻译前确保tran目录下已有原始文件的副本（未翻译的）
2. 如果tran目录下文件缺失，运行以下命令复制：
```powershell
Get-ChildItem -Name *.js | Where-Object { $_ -notin (Get-ChildItem tran -Name) } | ForEach-Object { Copy-Item $_ -Destination tran/ }
```
3. 翻译时保留特殊符号和占位符的完整性
4. 翻译对照库使用UTF-8编码
5. 变量拼接的字符串（如 `cm.sendNext("You want #b#t" + item + "##k?...")` ）需要完整翻译，包括JavaScript变量拼接部分
